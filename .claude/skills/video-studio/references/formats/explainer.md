# Explainer (60–180 s, typically 90 s)

Purpose: help someone *understand* — how a product works, a process, a concept. Usually VO-led.

## Structure (90 s)
| Time | Beat |
| --- | --- |
| 0–8 s | Hook — the relatable problem in one sentence/visual. |
| 8–20 s | Stakes — why the problem matters. |
| 20–30 s | Introduce the solution by name. |
| 30–75 s | How it works — 3 steps, each: label → visual demo → result. |
| 75–85 s | Outcome / proof (requester-provided numbers only). |
| 85–90 s | CTA end card. |

## Rules
- Write the VO script first in `notes/script.md`; time beats to the VO, not the other way round.
  ~150 words per minute of VO.
- On-screen text reinforces, never duplicates, the VO. Add captions for social versions.
- Diagrams and kinetic type over stock footage. Consistent icon style.
