# Promo / launch video (20–60 s, typically 30 s)

Purpose: explain *what* it is and *why it matters*, then drive one action. Clearer and more
direct than a trailer.

## Structure (30 s)
| Time | Beat |
| --- | --- |
| 0–3 s | Hook — the problem, a bold claim the requester provided, or the product in motion. |
| 3–8 s | Name it — product/event name + one-line value proposition. |
| 8–24 s | 3 proof points (features, benefits, social proof the requester supplied), ~5 s each, each with a visual (UI capture, footage, icon animation). |
| 24–30 s | CTA end card: logo, action, URL/date. Hold ≥ 2.5 s. |

## Rules
- One idea per beat; one CTA total.
- Product UI: show real screens from the requester; animate callouts/zooms on top rather than
  rebuilding UI from scratch unless asked.
- Feature-announcement variant: hook → "Introducing <feature>" → before/after → how it works in
  2 steps → availability + CTA.
