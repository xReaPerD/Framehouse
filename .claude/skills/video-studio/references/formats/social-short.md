# Social short — Reels / TikTok / Shorts / Stories (9:16, 6–60 s)

Purpose: stop the scroll and land the message **with the sound off**.

## Structure (15–30 s)
| Time | Beat |
| --- | --- |
| 0–1 s | Pattern interrupt — big motion or big text, in the centre safe zone. |
| 1–3 s | Text hook stating the payoff ("3 things you missed in…", "It's finally here"). |
| body | Fast beats (1–2 s), each with burned-in text. Captions for any speech. |
| last 3 s | CTA + logo; loop-friendly ending (last frame flows into the first) is a bonus. |

## Rules
- Respect vertical safe areas (`_common.md`): nothing important in the bottom 420 px or right 120 px.
- Recompose from landscape sources: reframe on the subject, stack elements vertically, enlarge
  type. Never just letterbox a 16:9 video.
- Text ≥ 56 px. High-contrast scrims behind text over footage.
- Stories (15 s max per segment) — keep each segment self-contained.
- 1:1 feed post (`post` cut): same rules, 72 px inset.
