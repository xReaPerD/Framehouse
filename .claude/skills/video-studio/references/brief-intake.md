# Brief intake

Goal: enough clarity to storyboard, with as few questions as possible. Read what the requester
gave you, map it onto the checklist, then ask only the **blocking** gaps in one message.

## Blocking — ask if missing
| Gap | Why it blocks |
| --- | --- |
| What it's for / the subject | No subject, no video. |
| The one-line takeaway or CTA | Decides the end card and the whole arc. |
| Hard facts to show (dates, prices, names, URLs, feature list) | Must never be invented. |
| Must-use assets that aren't attached yet | Can't build around footage you don't have. |

## Default unless told otherwise — write under *Assumptions*
| Field | Default |
| --- | --- |
| Deliverables | One landscape cut. Trailer → 60 s, teaser → 15 s, promo → 30 s. |
| Platform | YouTube / web, 16:9, sound on. |
| Vertical cut requested | 9:16, sound **off** by default → burned-in text, captions for any VO. |
| FPS | 30 (24 if the requester asks for "cinematic"). |
| Tone | Inferred from subject + brand voice; state it explicitly. |
| Music | Use provided track; else a royalty-free bed via `media-use`; note licence. |
| Voiceover | None. Text carries the message. |
| Client | Ask "who is this for?" only if it's unclear whether it's client work; record it with `--client`. |
| Brand | The project's own kit (`assets/brand/brand.json`). Draft → fill from the client's material; nothing supplied → propose one with the storyboard. |
| End card | Logo + one line (CTA / date / URL), held ≥ 2.5 s. |

## Good follow-up phrasing
> Before I storyboard, three quick things: (1) what's the one thing viewers should do after
> watching — visit a URL, wishlist, save the date? (2) is the launch date final enough to show
> on screen? (3) you mentioned gameplay footage — can you drop it in `inbox/`? Everything else
> I'll assume (listed in the brief) and you can override.

## Turning vague asks into specs
| They say | You write |
| --- | --- |
| "epic" | Low-register music build, slow push-ins, title cards with weight, a hard silence before the drop. |
| "fun / playful" | Bright palette, bouncy-but-short eases, quick cuts (≤ 1.2 s), sound-effect accents. |
| "premium / sleek" | Lots of negative space, restrained palette, long eases, fewer words. |
| "techy" | Monospace accents, grids, UI callouts, glitch/scan transitions used sparingly. |
| "like <famous trailer>" | Borrow the *structure and pacing* (cold open, rising cuts, button) — never its assets, music or text. |
