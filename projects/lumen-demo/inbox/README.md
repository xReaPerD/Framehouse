# inbox/

Drop raw source files here exactly as you received them: logos, screenshots, gameplay or product
footage, music, voiceover, scripts, reference videos, PDFs, brand guides — anything.

The agent will:
1. Inspect each file (type, resolution, duration, colour, audio levels).
2. Copy/convert what the video needs into `../assets/<kind>/` with clean, descriptive names.
3. Log it in `../brief.md → Assets`.

Originals stay here untouched so nothing is ever lost.
